## Summary

Binary classification of prostate cancer samples (primary versus
castration-resistant metastatic) from mutations and copy-number calls of
1,013 patients. Prior knowledge is the Reactome pathway hierarchy plus
Reactome gene sets. Three inputs per gene feed a gene layer, followed by
five pathway layers joined only along gene-to-pathway and child-to-parent
links. Every hidden layer has its own sigmoid head; the prediction is the
mean of the heads. Nodes are ranked by DeepLIFT scores, with an adjustment
for very high node degree.

## Prior-knowledge graph

- Source: Reactome `ReactomePathwaysRelation.txt`, `ReactomePathways.txt`,
  `ReactomePathways.gmt` (`data/pathways/reactome.py:9-11`), from a Google
  Drive archive (`README.md`, Installation 3a). Release not stated. Human
  relations are kept by an `HSA` substring test (`reactome.py:111`).
- Size: inputs 27,687 (3 per gene), genes 9,229, pathway layers of 1,387,
  1,066, 447, 147 and 26 nodes from the gene side up
  (`analysis/sup/n_params.py:2-9`, a pasted log). Paper: "slightly over
  71,000 weights". Directed, unsigned; Reactome is a DAG (multiple
  parents). After layering, every edge joins adjacent layers.
- Data to nodes: data genes are the union over data types, cut to a
  selected list and to protein-coding genes; gaps become 0
  (`data/prostate_paper/data_reader.py:209-235`). Symbols are matched to
  GMT gene sets (`data/gmt_reader.py:10-30`) by a left merge on the data
  genes (`model/builders/builders_utils.py:46-48`). Genes in no pathway
  keep a unit with no upward edge (61); an optional `UNK` pathway
  (53-58) is off. Reactome genes absent from the data are dropped;
  pathways with no data gene stay, with no incoming edge.
- Built at: `reactome.py:14-166`, `builders_utils.py:15-67`.

## Architecture

- Layers: inputs (mutation, deletion, amplification per gene), gene layer
  `h0`, pathway layers `h1`…`h5` ("params" lines 7, 20; "params" is
  `train/params/P1000/pnet/onsplit_average_reg_10_tanh_large_testing.py`).
  A virtual `root` sits above every in-degree-0 pathway
  (`reactome.py:115-119`); a pathway's layer is its shortest distance
  from `root` (40-48). The graph is cut at distance 5 (28); nodes there
  take their genes from the GMT file (152-165). Shallower leaves get copy
  chains down to distance 5 (14-37) that keep the original's name
  (57-59, 159). The `root` map is built but skipped
  (`builders_utils.py:194`).
- Units per node: one tanh unit with bias (params lines 34, 40).
- Connections that skip layers: none. Child lists are filtered to names
  in the next layer toward the data (`builders_utils.py:46-48,64`).
- Outputs or losses at inner layers: a `Dense(1)` + sigmoid head after
  `h0` and after each of `h1`…`h5` (`builders_utils.py:161-176,227-235`).
  All six are outputs (`model/builders/prostate_models.py:166-171`),
  with cross-entropy loss weights `[2, 7, 20, 54, 148, 400]` (params line
  23; `prostate_models.py:184-185`). The prediction is their mean
  (`model/nn.py:285-292`; params line 61).
- Parts the graph does not constrain: the six heads. Controls: the same
  widths with `Dense` layers (`builders_utils.py:213-215`) and a
  one-hidden-layer dense net (`prostate_models.py:335-375`).
- Other structure: dropout 0.5 after `h0`, 0.1 after pathway layers
  (params line 37). Optional attention gates are off
  (`builders_utils.py:136-139`).
- Defined at: `builders_utils.py:87-244`, `prostate_models.py:108-193`.

## Connectivity mechanism

Two custom Keras layers; neither stores a weight for an absent edge.

- Gene layer `Diagonal` (`model/layers_custom.py:94-194`): one weight per
  input (136-141). The forward pass scales each input and sums each block
  of `n_features / n_genes` consecutive columns (126, 158-162). Which
  inputs belong to a gene comes from column order alone
  (`data_reader.py:239-244`; gene list `cols.levels[0]`,
  `prostate_models.py:131-132`).
- Pathway layers `SparseTF` (`layers_custom.py:201-345`): from a 0/1 map
  (rows = lower nodes, columns = this layer's nodes) it keeps
  `nonzero_ind = np.nonzero(map)` (233-235) and a trainable
  `kernel_vector` with one entry per edge (254-258). Each forward pass
  scatters the vector into a dense zero matrix with `tf.scatter_nd`, then
  multiplies by it (297, 307). Absent entries are constants, so they get
  no gradient. `nonzero_ind` goes into the config, so clones keep their
  edges (324).
- Init: `lecun_uniform` on the 1-D edge vector (params line 44;
  `layers_custom.py:256`); biases start at zero (204). L2 per layer:
  0.001 on graph layers, 0.01 on heads (params lines 22, 24;
  `builders_utils.py:123,161-162,210,227-228`).

## Interpretation

- Method: DeepLIFT (Rescale rule) from a vendored, modified DeepExplain
  (`deepexplain/tensorflow_.py:331-372`). The default baseline is an
  all-zero input (114-118). For a hidden layer, the reference is its
  activation at that input (341); the score is gradient × (activation −
  reference) (343-345).
- Granularity: every input and every unit of `h0`…`h5`
  (`model/coef_weights_utils.py:229-258`), for one target: head `o6` (top
  pathway layer) in the figure pipeline
  (`analysis/figure_3/prepare_data.py:79`), the last output in `fit`
  (`nn.py:252-254`).
- Samples: per-sample scores are summed (`coef_weights_utils.py:247`)
  over the test set in the figure pipeline (`prepare_data.py:80`), which
  then takes the absolute value
  (`analysis/data_extraction_utils.py:113`). Scores saved in `fit` use
  training data (`nn.py:253`).
- Names: scores are zipped with the per-layer name lists from `get_pnet`
  (`nn.py:360-372`; `data_extraction_utils.py:108-121`). Inputs are
  labeled (gene, data type); Reactome IDs become pathway names (52-78).
- Degree adjustment (`data_extraction_utils.py:228-290`): degree is
  fan-in + fan-out, counted from nonzero trained weights (235-255; genes
  fan-out only, 244-249). A score is divided by it when it exceeds the
  layer mean + 5 SD (273-278). Figures rank by this `coef_combined`
  (`analysis/figure_3/figure_3_sankey.py:29`); z-scored copies are also
  saved (279-282).
- Other readouts: activations per sample and named node (`nn.py:320-330`;
  `prepare_data.py:46-55`), compared between classes for the top 10
  nodes (`analysis/figure_3/figure3_bc_activation_importance.py:154-186`);
  edge weights labeled by source and target (145-185); a Sankey diagram
  of top nodes per layer and the edges between them
  (`figure_3_sankey.py:125-216`).

## Fragile spots

- Header row: the relation and names files are read with pandas' default
  header (`reactome.py:73,85`), so a headerless file loses its first row.
  The analysis code reads `ReactomePathways.txt` with `header=None`
  (`data_extraction_utils.py:53`).
- The first relation column is labeled `child` (`reactome.py:86`) but
  acts as the parent (112, 116-119); the species test reads it only (111).
- Copy-node names: children are matched to the next layer by name
  (`builders_utils.py:46-48`), and copies share the original's name
  (`reactome.py:57-59,159`). An edge to a leaf at the parent's own depth
  can attach to that leaf's copy one layer down. Names in several layers
  are merged by a column-wise `min` (`data_extraction_utils.py:288-289`),
  which can mix one layer's score with another's `layer` value.
- No pruning (`builders_utils.py:46-64`): pathways with no incoming edge
  output a constant `tanh(bias)`; genes with no pathway reach only `o1`.
- Gene layer by position: `Diagonal` assumes equal, contiguous blocks in
  `cols.levels[0]` order (`layers_custom.py:126-131,158-162`). No name
  check.
- Reloading rebuilds the graph and loads weights by position
  (`nn.py:339-346`). Edge order follows `np.nonzero` of the rebuilt map
  (`layers_custom.py:233-235`); node order follows dict and set iteration
  (`builders_utils.py:16,26-28`; `reactome.py:42-48`). A new order with
  the same shapes loads without error.

## Paper vs code

- Paper: y = f[(M ∗ W)ᵀx + b] with a mask M. Code: one value per edge,
  scattered into a dense matrix (`layers_custom.py:254-258,297-307`).
- Paper: scores over test samples. Fit-time scores use training data
  (`nn.py:253`); the figure pipeline uses test data (`prepare_data.py:80`).
- Paper: the prediction is the heads' mean. DeepLIFT explains `o6` only
  (`prepare_data.py:79`).
- Paper: divide by "node degree". Code: fan-in + fan-out from trained
  weights, fan-out only for genes (`data_extraction_utils.py:244-255`).
- Dropout, L2 and the loss weights `[2, 7, 20, 54, 148, 400]` are in the
  parameters file; the Methods text I read gives none of these values.

```python
def complete_network(G, n_leveles=4):
    sub_graph = nx.ego_graph(G, 'root', radius=n_leveles)
    terminal_nodes = [n for n, d in sub_graph.out_degree() if d == 0]
    distances = [len(nx.shortest_path(G, source='root', target=node)) for node in terminal_nodes]
    for node in terminal_nodes:
        distance = len(nx.shortest_path(sub_graph, source='root', target=node))
        if distance <= n_leveles:
            diff = n_leveles - distance + 1
            sub_graph = add_edges(sub_graph, node, diff)

    return sub_graph
```
