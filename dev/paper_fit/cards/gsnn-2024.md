## Summary

GSNN predicts drug-induced gene expression (LINCS L1000 level 5, 24 h) from
drug dose and cell-line omics. The prior is a directed, cyclic interaction
graph from OmniPath (protein–protein, TF→RNA, miRNA) restricted to chosen
Reactome pathways, plus drug→target, omics→gene, and one output edge per
measured gene. The hidden state lives on edges: in each step every protein or
RNA node runs its own small network on its incoming edge values and writes one
value to each outgoing edge. The step is unrolled 10 or 20 times with residual
connections, and predictions are read from the edges into output nodes.
GSNNExplainer fits a per-sample edge mask that reproduces a prediction
relative to a baseline sample. Triage: included, not `gnn:`. PyG
`MessagePassing` serves only as a sparse product with one weight per stored
entry, and no weight is shared across edges or nodes
(`src/models/SparseLinear2.py:9-20`, `:64`).

## Prior-knowledge graph

- Source: five OmniPath tables (Dorothea TF→RNA, OmniPath and PathwayExtra
  protein→protein, TFmiRNA, miRNA RNA→RNA) fetched at run time with no version
  pin (`scripts/make_data.py:282-286`). Protein edges are kept only between
  UniProt IDs annotated to the chosen Reactome pathways
  (`scripts/make_data.py:292-341`); each experiment passes 11–17 pathway IDs
  (`scripts/experiments/exp1.sh:26`). Drug targets: CLUE `compoundinfo`
  (symbol → UniProt) plus Targetome, optionally STITCH
  (`scripts/make_data.py:433-466`).
- Node types: input (DRUG, EXPR, METHYL, MUT, CNV), function (PROTEIN, RNA),
  output (LINCS), named `TYPE__<id>` (`scripts/make_data.py:632-708`). A gene
  can have an RNA node and a PROTEIN node joined by a translation edge
  (`scripts/make_data.py:674-679`).
- Size (paper Table 4a, experiment 1): 5369 nodes (3505 input, 1411 function,
  453 output), 16203 edges; experiments 2 and 3 are similar. Directed,
  unsigned (the edge list keeps source, target, type, and two flags only,
  `scripts/make_data.py:632-672`), cycles allowed (paper; not checked in code).
- Pruning: drugs whose targets reach < 25 % of LINCS genes within 10 steps are
  removed (`scripts/make_data.py:508-534`); nodes with no directed path to any
  LINCS node are removed (`scripts/make_data.py:719-747`).
- Data to nodes: each feature is its own input node. Drug dose is
  log-transformed into its DRUG node (`scripts/make_data.py:171-181`). Omics
  genes in the bottom 10 % of variance or outside the protein/RNA space are
  dropped, the rest z-scored across cell lines (`scripts/make_data.py:584-610`),
  each with an edge to its RNA and/or PROTEIN node
  (`scripts/make_data.py:683-708`). Function nodes get input 0. Each measured
  gene in the RNA space gets one LINCS node with one edge from its RNA node
  (`scripts/make_data.py:668-672`), labels matched by gene id → UniProt
  (`scripts/make_data.py:790-796`).
- Built at: `scripts/make_data.py:632-779` (edge list, index, masks).

## Architecture

- Layers: L steps (grid 10 or 20, `scripts/batched_gsnn.sh:40`), each its own
  block unless `share_layers` (`src/models/GSNN.py:96-99`). Nodes have no layer;
  every node and edge takes part in every step, so signal travels at most L
  edges and cycles are traversed by repetition.
- Units per node: one scalar per edge; C hidden units per function node
  (grid 10 or 20, `scripts/batched_gsnn.sh:39`). Optionally C scales
  with degree: sqrt of in+out degree, clipped at 250, min-max scaled into
  [3, C] (`src/models/utils.py:236-278`). Optionally a second dense C×C layer
  per node (`two_layer_conv`, `src/models/utils.py:326-350`), off in the grid.
- Connections that skip layers: residual `out + x` per step
  (`src/models/GSNN.py:60`), final state divided by L (`:116`); without the
  residual, the initial state is added after every step (`:112`). Optional
  self-edge per function node, toggled in the grid (`:84-86`,
  `scripts/batched_gsnn.sh:41`).
- Outputs or losses at inner layers: none.
- Parts the graph does not constrain: the cell-viability predictor, a dense
  network trained in a second stage on the frozen GSNN's predicted expression
  or last edge states (`scripts/train_viabnn.py:108-147`, `:164-172`). The NN
  and GNN baselines are separate models.
- Other structure: per-node layer normalization, nonlinearity (ELU), and
  dropout on the hidden units (`src/models/GSNN.py:46-62`).
- Defined at: `src/models/GSNN.py:25-123`.

## Connectivity mechanism

Each step holds sparse weights only. W1 (E × ΣC) has one entry per (edge into
function node v, hidden unit of v) (`src/models/utils.py:306-315`); edges into
output nodes have none (`:309`). W3 (ΣC × E) has one entry per (hidden unit of
u, out-edge of u) (`:366-378`). Optional W2 is dense within each node only
(`:339-345`). Each sparse layer keeps a 1-D `values` parameter, one per present
entry, and a fixed index buffer (`src/models/SparseLinear2.py:64-65`). Forward
repeats the indices per sample with offsets (`:88-91`, `:110-148`) and runs a
PyG `MessagePassing` with `aggr='add'` and message `value * x[row]` (`:9-20`):
a scatter-add over stored triples. Absent entries do not exist and get no
gradient. Biases: one per hidden unit (W1) and one per edge for all E edges
(W3, `:66`). Initial values are normal with a per-entry scale from the nonzero
counts of the entry's row and column (He, Glorot, or LeCun; default `kaiming`,
`scripts/train_gsnn.py:114`), multiplied by `std**2`
(`src/models/SparseLinear2.py:44-62`). Inputs enter by copying each node value
onto its out-edges (`x[:, src]`, `src/models/utils.py:385-390`); outputs are the
states of edges into output nodes, placed at node positions with zeros
elsewhere (`:392-405`). Per-node normalization uses scatter mean and a
detached scatter std over each node's hidden units
(`src/models/GroupLayerNorm.py:23-37`).

## Interpretation

- GSNNExplainer: per sample, per edge (`src/interpret/GSNNExplainer.py:47-205`).
  Model weights are frozen (`:84-88`). Two logits per edge start at ±prior
  (`:134-136`); a hard Gumbel-softmax, temperature annealed 3 → 0.5, gives keep
  (`mask2`) and drop (`mask1`) weights (`:153-161`). A re-implemented forward
  sets every edge state, at the input and after every step, to
  `mask1 * baseline_state + mask2 * state` (`:25-44`), with the baseline's
  per-step states precomputed (`:10-22`, `:120`). Loss: MSE between masked and
  full output differences from the baseline prediction, plus
  β·max(0, Σmask2 − free_edges) (`:169-173`). Result: keep probability per edge
  as a table with source and target names from `node_names[edge_index]`
  (`:197-200`), plus the R² of the thresholded subgraph (`:184-192`).
- Baselines: the same sample with all DRUG inputs set to 0, or a sample from
  another cell line (`notebooks/EDGE_IMPORTANCE_SCORES.ipynb` code cells 9,
  24-26). Five explainer runs on one sample are merged on (source, target) and
  compared by pairwise correlation and pairwise means (cells 9-14).
- Node scores: edges with score > 0.5 form a subgraph; its largest weakly
  connected component gives each node a degree centrality, z-scored per node
  across observations and correlated with omics
  (`notebooks/IMPORTANCE_SCORE_OMICS_ANALYSIS.ipynb` cells 8-11).
- `extract_entity_function` rebuilds one node as a small dense network
  (`src/interpret/extract_entity_function.py:35-115`); notebooks never call it.

## Fragile spots

- `bias=~args.no_bias` (`scripts/train_gsnn.py:229`) is -1 or -2, both truthy,
  so `--no_bias` has no effect; the no-bias branch uses `bias_idx` before
  assignment (`src/models/SparseLinear2.py:97-98`).
- W3's bias spans all E edges (`src/models/GSNN.py:15`,
  `src/models/SparseLinear2.py:66`), so input edges, which no node writes,
  still get a trainable offset added every step.
- The explainer re-implements the step loop
  (`src/interpret/GSNNExplainer.py:10-44`) instead of using the model's `mask`
  argument (`src/models/GSNN.py:113`); changes to `GSNN.forward` do not reach it.
- The edge list is concatenated without de-duplication
  (`scripts/make_data.py:710`); a pair in two tables becomes two edges.
- `extract_entity_function` normalizes only if `hasattr(model, 'norm')`
  (`src/interpret/extract_entity_function.py:108`), which a GSNN never has
  (`norm1` lives on each block, `src/models/GSNN.py:38`).
- `IMPORTANCE_SCORE_OMICS_ANALYSIS.ipynb` cell 9 calls
  `get_scores(obs.index[4], ...)` for each of 15 rows and labels each result
  with that row's drug, dose, and cell line.

## Paper vs code

- Initialization: the paper gives w ~ N(0, 2/D_in) (He) and
  N(0, 2/(D_in + D_out)) (Glorot); the code multiplies a standard normal by
  the variance, not its square root (`src/models/SparseLinear2.py:61-62`).
- Dropout grid: paper Table 3 lists 0 and 0.25; the grid script uses 0 and 0.1
  (`scripts/batched_gsnn.sh:38`).
- Paper Table 3 lists `scale_channels_by_degree`; the grid script never passes
  it (`scripts/batched_gsnn.sh:65-66`), so those runs use C units per node.
- Not in the text read: dividing the final state by L
  (`src/models/GSNN.py:116`), the explainer's `free_edges` budget of 500–4000
  (`notebooks/EDGE_IMPORTANCE_SCORES.ipynb` cells 9, 26; the paper names a
  weight decay γ, the notebooks pass 0), and node centrality from explanations.

```python
    def forward(self, x):

        out = self.lin1(x)
        if hasattr(self, 'norm1'): out = self.norm1(out)
        out = self.nonlin(out)
        out = torch.nn.functional.dropout(out, p=self.dropout, training=self.training)

        if self.two_layers:
            out = self.lin2(out)
            if hasattr(self, 'norm2'): out = self.norm2(out)
            out = self.nonlin(out)
            out = torch.nn.functional.dropout(out, p=self.dropout, training=self.training)

        out = self.lin3(out)
        if self.residual: out = out + x

        return out
```
